# 시빅 정비수첩

`hodu-ho.me/civic/`. 혼다 시빅 1.8 (31버7847, FD1, 2008년식, 등록 2007-12-21)의 소모품 교체 시점과 종합검사 시기를 안내하고, 정비 이력·비용 통계를 보여 준다. 청첩장과 같은 레포에 있지만 코드·스타일은 공유하지 않는 독립 페이지다. 빌드 없음.

## 파일

| 파일 | 역할 |
| --- | --- |
| `data.js` | 데이터 원본. `window.CIVIC_DATA` |
| `logic.js` | DOM 없는 순수 함수(날짜, `calcPart`, CSV 입출력). `window.CivicLogic` |
| `script.js` | 화면 렌더링과 동작 |
| `car.js` | 히어로의 회전하는 시빅 |
| `fonts/` | 도깨비DNR 고딕 woff2와 `OFL.txt` |
| `civic-log.html` | 레포로 옮기기 전 아티팩트 원본(참고용). https://claude.ai/artifact/Vc6Tyg4DBW3CXhSJRNGWfK |
| `seed.json` | `data.js`로 옮기기 전 데이터(차량 정보·주행거리 기준일 없음) |

`index.html`에서 `data.js` → `logic.js` → `script.js` → `car.js` 순서로 불러온다. 외부 의존성은 Pretendard 웹폰트(jsDelivr, wedding과 같은 v1.3.9)뿐이다.

## 운영 방식

- 보기 전용. 정비를 받으면 `data.js`를 직접 고친다. 서버·구글 시트 연동은 보류.
- 편집 기능(추가·수정·삭제 폼, 오늘 교체함, 주행거리 수정, 이슈 완료, 데이터 탭의 백업·CSV)은 코드에 남겨 두고 `script.js`의 `EDIT = false`로 끈다. 버튼을 숨기고 클릭 처리에서도 막는다. 켜면 `localStorage`에 저장하며, 비어 있으면 `data.js`에서 시작한다.
- 주행거리는 `settings.currentKm`과 기준일 `settings.kmDate`로 표시한다.
- 구글 시트로 갈 경우: 드라이브 커넥터는 CSV로 새 시트를 만들 수만 있고 기존 시트를 덮어쓸 수 없었다. Sheets API나 Apps Script로 직접 읽고 써야 한다. 레포와 사이트가 공개라 Apps Script 주소가 노출되므로 쓰기(필요하면 읽기도)를 비밀 키로 막아야 한다.

## 판단 규칙

- 교체 주기(`calcPart`): ratio = max(사용 km ÷ 주기 km, 경과 기간 ÷ 주기 개월). 기준 없음 `none` / ratio ≥ 1 `over` / ratio ≥ 0.85 `soon` / 그 외 `ok`.
- 오늘 교체함(편집 켰을 때): lastDate = 오늘, lastKm = 현재 주행거리.
- 종합검사 가능 기간: 다음 검사일 −90일 ~ +31일.
- 누적 정비비는 자비 정비만 센다. 보험 수리·견적은 제외(통계 탭에서 보험 포함 토글).

## 데이터 모델 (`data.js`)

- `records`: date, km, shop, shopType(honda|general), kind(repair|insurance|estimate), title, items[], amount, note
- `parts`: name, intervalKm, intervalMonths, lastDate, lastKm, note
- `inspections`: date, km, result, nextDate, note
- `issues`: text, status(open|done), since
- `settings`: plate, model, currentKm, kmDate (주행거리는 2026-03-12 정비 기록의 256,983 km)

## 데이터 주의점

- 교체 주기는 공식 취급설명서 확인 전이다. 아래 "교체 주기 출처"의 웹 참고값이며, 출처가 없는 항목은 처음 넣은 임시값 그대로다.
- 2025-10-13 정비(2,611,290원): 문서 하단 손글씨 `−961,290 / 1,650,000`이 실제 지불액을 뜻할 수 있으나 문서로 확정할 수 없다. 앱은 2,611,290으로 집계한다. 수리비 누계 6,447,200원(수리 10건), 1,650,000이 실제라면 5,485,910원.
- 2024-04-29 보험 수리(3,385,030원)의 본인 부담금은 문서에 없다.
- 2026-03-12 좌측 사이드미러 견적(466,950원)은 작업 기록이 없어 이슈로만 등록했다.
- 2025-12-26 종합검사: 적합이지만 헤드·오일팬·엔진 앞 케이스 누유(심함) 보완 권고, 자기진단 센서 점검은 "진단불가(통신 이상)".
- 주민등록번호·차대번호는 넣지 않는다. 레포와 사이트가 공개다.

## 폰트

- 히어로(제목·번호판·계기판)는 도깨비DNR 고딕(`.px`), 나머지는 Pretendard.
- 도깨비DNR은 `~/GitHub/font` 릴리스 v1.0.2의 woff2를 직접 호스팅한다.
- 16×16 셀 비트맵 기반이라 16px·32px에서만 선명하다. 다른 크기를 쓰지 않는다.
- GSUB이 없어 `tnum`이 안 된다. 숫자를 세로로 정렬해야 하는 곳은 Pretendard `tabular-nums`를 쓴다.
- 차트는 SVG `viewBox`로 늘어나므로 픽셀 폰트를 쓰지 않는다.

## 히어로 시빅 (`car.js`)

- 라이브러리 없이 캔버스 `ImageData`에 직접 래스터라이즈한다. 로프트(단면 연결)로 차체·유리 부분, 12각 실린더로 바퀴.
- 형상은 FD 세단 청사진(getoutlines.com `honda-civic-4dr-2006.gif`, CC BY 4.0) 옆모습을 휠베이스 2,700mm = 341px(약 7.9mm/px)로 환산해 `SILL`·`BELT`·`HALF`·`ROOF` 프로파일로 옮겼다. 프로파일은 단조 3차 보간, 단면은 4cm 간격으로 자동 생성.
- 디테일 참고 사진: 위키미디어 커먼즈 `Honda CIVIC 1.8GL (DBA-FD1) front/rear.jpg`(CC BY-SA 4.0).
- 차는 전기형(2006~2008) 국내 사양 FD1. 전·후기형 차이는 앞범퍼·그릴·테일램프뿐이라 실루엣은 같다.
- 완벽 재현보다 특징 살리기가 목표다.
  - 차체 어깨와 유리 부분 단면은 슈퍼타원으로 굴렸다. 어깨선은 휠 아치와 무관하게 보닛 높이만 따른다.
  - 탑승부 높이는 실측의 1.5배(`LIFT`)다.
  - 앞유리 밑단(카울)은 실측보다 12cm 뒤(x=1.17m)다.
- 램프·그릴·흡기구·테일램프·휠 스포크는 면 재질이 아니라 픽셀마다 3D 위치로 칠하는 데칼(`facePaint`, `spokes`)이다. 앞모습 치수는 청사진 정면도 실측(약 5.8mm/px): 헤드라이트 지상 0.58~0.78m, 중심에서 0.44~0.86m, 그릴 0.57~0.68m, 하단 흡기구 0.29~0.45m.
- 휠은 FD1 1.8 순정 은색 5스포크.
- 유리·A필러·지붕 레일은 벨트~지붕 높이 비율(u)로 픽셀마다 칠한다(`glassPaint`). 옆 유리는 u 0.8 아래, 지붕 레일은 그 위다. 앞·뒷유리는 옆 위치(|z|)로 경계를 잡아 아래가 넓은 사다리꼴(앞유리 0.70m→0.53m)이고, A필러는 그 바깥 0.11m 띠다. 위 끝이 지붕 레일 위치와 맞아 이어진다.
- 명암은 3단계 + 팔레트. 위를 향한 면(법선 y > 0.8: 보닛·지붕·덱)은 늘 가장 밝은 톤이다. 명암 경계가 곡면을 가로지르면 굴곡처럼 보여서다.
- 실루엣과 깊이 차 0.35m 이상인 곳에 1px 외곽선. 그림자 색은 `--line`을 읽어 테마를 따른다.
- 내부 해상도 가로 최대 150px × 56px, CSS로 3배(600px 이상은 4배) 정수 확대. 12fps로 끊어서 회전하고 드래그로 돌린다.
- `prefers-reduced-motion`이면 3/4 앵글로 정지하고, 화면 밖이거나 탭이 숨으면 멈춘다.
